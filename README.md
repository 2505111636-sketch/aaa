# Route Rescue

无障碍行程恢复协同系统。乘客提交出行需求，源站接应、目标站确认交接，最后由乘客确认完成。管理员维护设施状态并查看运营数据。

本源码整理自正式站 V4：<https://cng6c22v2wdr.meoo.fun/>。界面和业务流程沿用现有版本，工程收敛为 React + TypeScript 前端、Node.js 服务端和 SQLite / PostgreSQL 数据存储。默认本地运行使用 SQLite，无需注册云服务。

## 快速启动

安装 **Node.js 24 或更新版本**，在项目根目录运行：

```sh
npm ci
npm run setup
npm run build
npm start
```

打开 <http://localhost:3000>。Windows 也可双击根目录的“启动应用.cmd”。首次需要联网下载依赖；安装完成后，本地模式不依赖地铁接口或云端数据库。

依赖源在 `.npmrc` 中统一配置为 npm 镜像，与锁文件保持一致；如需切换源，请同时重新生成并验证锁文件。

`npm run setup` 只在没有 `.env` 时创建配置并生成维护账号的私有密码。公开体验账号已预填，直接点击登录即可。后续启动不会覆盖配置或清空数据库。

开发时运行 `npm run dev`。页面支持热更新，服务端源码修改后自动重新编译并重启。

## 常用命令

| 命令                   | 用途                                           |
| ---------------------- | ---------------------------------------------- |
| `npm run check`        | TypeScript 类型检查                            |
| `npm test`             | 权限状态机、日期统计、标识生成等单元验证       |
| `npm run test:api`     | 启动独立测试服务和临时数据库，验证完整接口流程 |
| `npm run format`       | 统一代码格式                                   |
| `npm run format:check` | 检查格式是否一致                               |

运行接口测试前先执行 `npm run build`。测试使用独立临时数据库，不读取本机业务数据库；请通过上述命令运行，避免手动把测试脚本指向正式站。

## 数据与功能范围

初始场景为中央车站2号电梯故障，乘客可以选择东湖广场或市民中心恢复行程。请求、进度、交接、事件时间线和管理审计写入数据库，刷新或重启后保留。首次本地运行会自动创建数据库表。

一键重置清空本轮乘客与工作人员的任务、时间线和页面选择，其他设备通过场景版本同步回到起点。管理员运营档案独立于本轮记录，提供固定截止到2026-10-18的7／14／30天历史统计。

本项目用于竞赛展示。站点、人物、设施、路线与历史运营档案均为虚构设定；未接入真实地铁接口、室内定位、车辆调度、短信或电话。请使用虚拟信息体验。
