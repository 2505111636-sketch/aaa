## 一键重置的范围

页头“一键重置”现在操作服务器中的整个竞赛体验场景：清空全部乘客和工作人员任务（包含旧的归档任务）、时间线，管理概览和趋势归零；恢复 A站2号电梯故障、B/C站设施正常。登录会话保留，方便直接重新开始。

每次重置在同一数据库事务中清空任务、恢复设施并更新统一版本标记。所有设备下一次同步会清空选项、补充说明、工作人员准备项、个人出行与阅读偏好，并回到角色的初始工作页面。浏览器刷新后清空结果仍保留。管理员管理页的重置按钮也使用该流程。

所有固定体验账号拥有“重新开始场景”这一特定权限。`POST /api/reset` 仍要求应用登录、同源 JSON 和 `confirm: RESET_ALL`；普通角色不能因此读取总体统计或修改设施。匿名首页按钮通过公开体验账号完成一次受认证的重置，再退出临时会话。数据重置保留操作审计。

旧的 `/api/admin` 归档接口保留兼容性，继续仅允许管理员；界面上的“一键重置”和确认重置均使用新的完整清空流程。
