# 管理员运营档案

运营概览、服务分析默认展示运营档案，可切换“本轮服务”读取实际请求。管理员首页和个人中心补齐近7天档案摘要；个人资料使用许知远这一虚构角色。

档案是竞赛专用的虚构历史数据，固定截止到2026-10-18，共60天，定义在服务端 `lib/operations-archive.ts`，通过同一个汇总函数计算7/14/30天的请求、完成、取消、需求、站点协同和事件时长。前端不会把它标记成实时业务，档案截止日期和范围始终可见。“关于”页说明数据来源；不接入真实地铁系统。

`GET /api/insights?source=archive&days=7` 只向管理员返回汇总，不返回个人明细。省略source或使用live，仍返回原有数据库统计，保持既有接口兼容。当前设施状态始终从数据库读取，并明确标为“当前”。

一键重置清空本轮任务、时间线、选择和偏好，不改变独立的历史档案。本轮服务统计归零，档案可继续用于数据展示。乘客和工作人员队列不会出现历史预设任务。

验证：`node tests/operations-archive.mjs`；另有正式站移动浏览器对个人中心、时间范围、图表、每日数据和权限的验收记录。
