# 测试与验收

```sh
npm run check
npm test
npm run build
npm run test:api
```

接口测试自动创建临时SQLite数据库和独立服务，完成后停止服务。测试数据库路径会打印在终端，便于检查失败现场，不会写入项目默认的 `data/`。

验证覆盖：

- 乘客和工作人员的数据隔离、跨站权限与状态机。
- 重复请求、并发接单、过期版本、取消、退回队列与完成确认。
- 登录、退出、错误来源、无效输入和公开账号与维护账号的分离。
- 全场景清空、恢复起始设施、刷新后持久保留以及重新开始。
- 北京时间边界、历史周期比较、服务时长和运营档案聚合一致性。
- Cookie合并及非HTTPS环境下的请求标识生成。

`test-results/` 保存最近一次接口测试结果，属于运行产物，默认不进Git。正式站历史验收资料与整理版测试资料分别保存；不能用旧站报告代替整理版验证。
