通过 Figma 插件读取 14 个完整页面的结构、样式、截图和素材：乘客端 1–9；工作人员端 1–5。初次页面级上下文未返回有效内容后，读取结构并逐页获取高精度上下文与截图。下载 228 项原始图片和 SVG；保留在 public/figma。design/assets.json 记录每个页面的素材映射，geometry.json 记录原始 SVG 根尺寸。所有素材使用本地路径，无临时 Figma URL 运行依赖。

保留城市列车插画、Logo、设施插画、虚拟工作人员头像、导航图标，珊瑚橙/奶油渐变、半透明卡片、圆角按钮、服务时间线与四项底部导航。SVG 使用保留原始尺寸的图片和外层比例变换。页面原稿为约 174×378 的缩小版手机稿，按真实浏览器阅读尺寸重排；手机端采用流式布局，桌面增加项目说明侧栏。字体使用系统中文字体回退，未获得原稿 Alibaba PuHuiTi 字体文件。浏览器使用本机状态栏，未重复绘制原稿 iPhone 状态栏与 Home Indicator；这些 Code Connect 组件属于 iOS 原生系统，仓库没有对应 React 实现。

为了补齐业务增加：角色登录、权限提示、管理入口、加载骨架、空列表、失败重试、取消确认、2分钟无人接单、交接接收确认、服务完成确认、演示边界说明。按钮文字采用较深颜色以提高渐变背景上的可读性。原稿中的“已接入控制中心”“实时设备监测”“车辆调度”等真实能力文案改为明确的演示说明。
